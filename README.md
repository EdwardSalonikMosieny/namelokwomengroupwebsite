# Namelok Women Self-Help Group

Static website for Namelok Women Self-Help Group, focused on climate resilience, sustainable livelihoods, and dignity for indigenous Maasai women and girls in Laikipia North.

## Files

- `index.html` - Semantic single-page website structure.
- `style.css` - Mobile-first responsive styling.
- `script.js` - Menu toggle, smooth scrolling, contact form message, copyright year, and reveal animations.
- `Assets/` - Existing project photos used by the website.

## Run

Open `index.html` directly in a browser. No build step, backend, or external framework is required.
